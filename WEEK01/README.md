Reflection

This Week 1 activity helped me understand the importance of preparing a professional technical environment before beginning more advanced System Administration activities. I learned that a System Administrator needs more than technical knowledge. Organization, documentation, version control, and continuous learning are also important skills.

Installing Git taught me how version control can be used to track changes to files and projects. GitHub and GitHub Desktop also helped me understand how technical work can be organized and shared through repositories. Creating the BSIT-SystemAdministration-Portfolio repository gave me a central location where I can store my laboratory activities and projects throughout the semester.

I also learned how Visual Studio Code can be used for programming and technical documentation. Setting up VirtualBox was particularly useful because virtualization allows me to practice installing and managing different operating systems without requiring separate physical computers. Preparing the Ubuntu and Windows ISO files will also make it easier to complete future server and operating system activities.

Creating my GitHub and LinkedIn accounts helped me recognize the importance of building a professional digital identity. As an IT student, maintaining a portfolio can demonstrate my skills and progress to future employers or internship opportunities.

Overall, this activity established the foundation for my System Administration studies. The tools I installed will allow me to practice version control, virtualization, documentation, operating system administration, and other technical skills. I believe that maintaining an organized portfolio throughout the semester will help me become more professional, disciplined, and prepared for a future career as a System Administrator.
